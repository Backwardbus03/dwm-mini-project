Input Features

🧪 AQ-10 Questionnaire Features (14 total)

  • •10 AQ-10 Questions (A1-A10): Behavioral/cognitive assessments
  • •Age: Continuous variable in years
  • •Gender: Categorical (Male/Female)
  • •Jaundice: Born with jaundice (Yes/No)
  • •Family History: Family member with ASD (Yes/No)

👶 Q-CHAT-10 Toddler Features (14 total)

  • •10 Q-CHAT Questions (A1-A10): Early developmental assessments
  • •Age in Months: Continuous variable (12-36 months)
  • •Gender: Categorical (Male/Female)
  • •Jaundice: Born with jaundice (Yes/No)
  • •Family History: Family member with ASD (Yes/No)

Machine Learning Algorithm

We employ Random Forest Classifiers, a powerful ensemble algorithm that combines multiple decision trees for robust predictions.

Model Architecture

  • ✓100 Decision Trees per model
  • ✓Max Depth: 10 to prevent overfitting
  • ✓Class Balancing: Weighted for imbalanced data
  • ✓Validation: 80/20 stratified train-test split

Preprocessing Pipeline

  • →One-Hot Encoding: For categorical features
  • →Standardization: Normalizes numerical features
  • →Imputation: Handles missing data
