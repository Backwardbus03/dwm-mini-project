Understand the technology behind this tool and find reliable resources for further information.

Machine Learning Model

This tool uses a Random Forest Classifier, a powerful and widely-used machine learning algorithm. Here's why it was chosen:

  • Accuracy: It is known for high accuracy on diverse datasets.
  • Robustness: It handles missing values and maintains performance even with varied data.
  • Interpretability: It can determine the importance of different factors (e.g., which question is most predictive).

The model was trained on the datasets you can explore on the Dashboard & Analytics page.

AQ-10 Scoring Logic

Important: Not all "Yes" answers indicate an ASD trait. Some questions are reverse-scored.

  • Score 1 point for 'Yes' on questions: A1, A7, A8, A10.
  • Score 1 point for 'No' on questions: A2, A3, A4, A5, A6, A9.

The application automatically applies this logic before sending the data to the model.
