🎯 Input Features

The model uses 14 input features to make predictions:

AQ-10 Questionnaire

  • A1-A10: Ten validated screening questions
  • Measures social interaction, communication, and behavioral patterns
  • Reverse-scored questions (A2, A3, A4, A5, A6, A9)
  • Direct-scored questions (A1, A7, A8, A10)

Demographics

  • Age: Participant's age in years
  • Gender: Male or Female
  • Jaundice: Born with jaundice (yes/no)
  • Family ASD: Family member with PDD (yes/no)

🤖 Model Architecture

We employ Random Forest Classifiers - a powerful ensemble learning algorithm that combines multiple decision trees for robust predictions.

Model Configuration

  • 100 estimators: Ensemble of 100 decision trees
  • Max depth: 10: Prevents overfitting while maintaining accuracy
  • Balanced class weights: Handles class imbalance effectively
  • One-hot encoding: Categorical features transformed appropriately
  • Separate models: Individual models for each age group

Training Process

  • Train/Test Split: 80/20 stratified split
  • Random State: 42 (for reproducibility)
  • Preprocessing: Automated pipeline with sklearn
  • Validation: Cross-validation on training set
