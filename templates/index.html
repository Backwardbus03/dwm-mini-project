Welcome to the ASD Screening & Analytics Hub 🧠

This application is a comprehensive tool for Autism Spectrum Disorder (ASD) screening, built using machine learning. It provides key functionalities to help users understand and explore ASD traits.

How to Get Started

  1. 🧪 ASD Screener: Navigate to the screener page to begin a new assessment. This interactive tool will guide you through the AQ-10 questionnaire.
  2. 📊 Interactive Analysis: Visit the analysis page to explore which factors are most predictive for different age groups, based on our machine learning models.
  3. 📚 Methodology & Resources: Learn about the underlying technology and find links to professional resources for more information and support.

Disclaimer: This tool is for informational and screening purposes only. It is not a substitute for a professional medical diagnosis. Please consult a qualified healthcare professional for an accurate diagnosis.
